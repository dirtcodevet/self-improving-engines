    How

    Drag turn · Right-drag or Shift-drag pan · Wheel / pinch zoom
    Click a dot: pick it · Shift-click: add / remove · Ctrl- or Alt-drag (or Box): pick all visible dots in a box
    Run: pick two grid dots on one grid line, then Run fills the series between them.
    Zoom in until dots separate to pick one exact vertex (a click takes the visible dot nearest the pointer). Blue dots are the part's address grid, laid on the skin (small dots: the finer grid over small features); grey dots are mesh vertices. A grid dot's name is its address. A vertex is written in the part's address system when that address lands back on it, otherwise as xyz (nearest surface point). Addresses re-resolve on a later or remeshed build of this part; vertex numbers are listed for this build only. Addresses pasted from the earlier grid (h+, h-, tube) still resolve.
