# Research brief template (shared by every reference researcher)

Purpose: cited numbers that let a 3-D body engine build and check human anatomy by measurement and math (the person's
method: everything is quantifiable - size, proportion, ratio, density, curvature, mass - and nothing about the model is
asserted without its measurement). Each researcher covers one topic and writes ONE file in this folder.

Rules
- Read-only web research. Do not download files (reading web pages and abstracts is fine). If a fetch tool caches a file
  by itself, say so in the reply; do not keep files you made.
- Clinical, anatomical, anthropometric, biomechanical and engineering sources; adults unless the topic says otherwise.
  Anatomical topics are clinical and descriptive only.
- For every value: number, unit, n, population (age, sex, ancestry where reported), method, citation (authors, year,
  journal or book or standard, DOI or PMID or ISBN), confidence (strong: several studies agree / single / weak: abstract,
  snippet, secondary or unverified). Give means with SD or ranges; say where sources disagree and give the range.
- Say plainly where no value exists. Mark anything you derived yourself as derived.

The file
- Start with a short section in your own words: (1) how the structure is built (layers, parts) and how it behaves
  (movement, deformation, variation with age, sex, build); (2) a list of measurable descriptors a mesh can be checked
  against, each with its cited target and spread; (3) how to measure them on a 3-D mesh (landmarks, sections, curvature,
  volumes).
- Then compact tables by sub-topic, one line per value; a short "not found" list; a keyed reference list.
- Under about 180 lines, ASCII.

Reply to the orchestrator in at most 12 lines: the key numbers, the biggest gaps, and any file the tools cached.
